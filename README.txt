icygallery
==========

1. Put your postcards / artwork into the "images" folder (jpg, png, webp, gif, avif).
   Delete the sample-postcard files when you no longer need them.
2. Run:  python update_gallery.py
   (this refreshes images.js with everything in the folder)
3. Open index.html in a browser, or upload the whole folder to any static host
   (GitHub Pages, Netlify, Cloudflare Pages, etc.).

Tip: images are shown in alphabetical order of their file names, and the enlarged
view shows each one's number (e.g. "3 / 12"). Name files 01-..., 02-... to control order.
